# Valoria Vision — V0.6.0 Gel socle & audit sécurité

Date : 2026-07-07

## Statut
La V0.6.0 est validée fonctionnellement et visuellement.

## Objectif
Geler le socle fonctionnel actuel et cartographier les données sensibles avant :
- chiffrement de la base ;
- chiffrement des sauvegardes ;
- mot de passe maître ;
- verrouillage applicatif ;
- futur Open Banking.

## Décision de pilotage
Aucune bêta privée avec données réelles ne doit être lancée tant que :
1. la base locale n’est pas protégée ;
2. les sauvegardes ne sont pas protégées ;
3. l’accès applicatif n’est pas protégé.
