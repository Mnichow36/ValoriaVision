# V0.6.6-R6.1 — Rapprochements simplifiés

## Objectif

Remplacer l'écran de rapprochements trop complexe par une interface simple :

- à gauche : transactions bancaires importées ;
- à droite : récurrences/occurrences prévues ;
- cases à cocher pour faire le rapprochement manuel ;
- KPI cliquables dans un panneau vertical à droite.

## Utilisation

1. Cliquer sur `Générer / mettre à jour`.
2. Cocher une transaction bancaire à gauche.
3. Cocher une occurrence prévue à droite.
4. Cliquer sur `Rapprocher les cases cochées`.

## Conservation

Le rapprochement automatique après import reste disponible.
Le moteur graphique Plotly n'est pas modifié.
