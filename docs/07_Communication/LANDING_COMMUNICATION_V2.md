# Valoria Vision - Landing page V2 et campagne de communication

Date de cadrage : 2026-08-28
Statut : cadrage operationnel
Tickets lies : LANDING-1, SEO-1, ANALYTICS-1, MEDIA-1

## Objectif du chantier

Refondre la landing page et la communication publique de Valoria Vision pour gagner en clarte, en credibilite et en visibilite, sans promettre une version produit qui n'est pas encore livree.

Le chantier doit servir trois objectifs :

1. expliquer clairement le positionnement de Valoria Vision ;
2. ameliorer le referencement naturel du site ;
3. convertir les visiteurs LinkedIn et Google vers une liste d'attente ou une beta privee.

## Positionnement public a appliquer

Valoria Vision doit etre presente comme :

> Une application locale de gestion financiere personnelle pour suivre son cash, ses comptes, ses budgets et son patrimoine, sans connexion bancaire permanente imposee, avec un socle de base gratuit et une trajectoire premium pour les usages avances.

Points a mettre en avant :

- application locale ;
- confidentialite et controle utilisateur ;
- absence de connexion bancaire permanente imposee ;
- imports maitrises ;
- automatisation locale progressive ;
- socle de base gratuit ;
- fonctions premium futures ;
- produit encore en construction, avec recettage et beta progressive.

## Regles de prudence communication

| Sujet | Formulation autorisee | Formulation a eviter |
|---|---|---|
| Statut produit | En construction, recettage en cours, beta progressive | Disponible commercialement |
| Maquettes UI R8 | Direction graphique, maquette cible, future interface | Nouvelle interface deja disponible |
| Gratuit | Socle de base gratuit | Logiciel entierement gratuit |
| Premium | Fonctions premium prevues pour les usages avances | Tout sera gratuit |
| Agregateurs | Pas de connexion bancaire permanente imposee | Les concurrents sont moins securises |
| Securite | Approche locale et maitrisee qui reduit certaines dependances | Application inviolable |

## Structure cible de la landing page V2

### 1. Hero

Objectif : faire comprendre Valoria Vision en moins de 5 secondes.

Titre propose :

> Pilotez votre cash, vos comptes et votre patrimoine sans connexion bancaire permanente.

Sous-titre propose :

> Valoria Vision est une application locale de gestion financiere personnelle, pensee pour donner une vision claire de vos finances avec un socle de base gratuit et des fonctions premium a venir.

CTA principal :

> Rejoindre la liste d'attente

CTA secondaire :

> Decouvrir le parti pris

Visuel :

- maquette UI R8 clairement etiquetee "maquette cible" ;
- ou capture actuelle uniquement si elle est modernisee / assumee comme provisoire.

Mention recommandee sous visuel :

> Apercu de la direction graphique en cours de conception.

### 2. Le parti pris Valoria Vision

Titre :

> Une autre approche de la finance personnelle

Contenu :

Valoria Vision ne cherche pas a tout connecter automatiquement. Le projet privilegie une approche locale et maitrisee : importer, organiser, analyser et rapprocher les donnees sans imposer une connexion bancaire permanente.

Cartes a afficher :

| Carte | Message |
|---|---|
| Local | Les donnees restent sous le controle de l'utilisateur. |
| Maitrise | Les imports et traitements sont explicables. |
| Sobriete | Moins de dependance quotidienne aux API bancaires. |
| Evolution | Automatisation locale progressive, sans opacite. |

### 3. Les modules produit

Titre :

> Une vision complete, progressive et lisible

Modules a presenter :

| Module | Promesse courte |
|---|---|
| Dashboard | Suivre rapidement les indicateurs essentiels. |
| Comptes | Centraliser les soldes et comptes suivis. |
| Transactions | Importer, categoriser et analyser les operations. |
| Budgets | Comparer prevu et realise. |
| Previsionnel | Anticiper les mouvements futurs. |
| Patrimoine | Suivre actifs, passifs et patrimoine net. |
| Rapprochements | Relier les previsions aux transactions realisees. |

Ne pas presenter les modules non finalises comme totalement disponibles.

### 4. Automatiser sans tout connecter

Titre :

> Automatiser l'integration, sans imposer la synchronisation bancaire permanente

Message :

Valoria Vision peut automatiser des routines locales : detection de fichiers, reconnaissance de formats bancaires, categorisation, controle des doublons et rapprochement previsionnel/reel.

Liste courte :

- imports CSV/QIF controles ;
- reconnaissance du compte source ;
- detection des doublons ;
- categorisation automatique locale ;
- rapprochement entre previsionnel et realise ;
- annulation et tracabilite des imports.

### 5. Socle gratuit et premium futur

Titre :

> Un socle gratuit, une trajectoire premium

Message :

Valoria Vision vise un socle de base gratuit pour rendre la gestion financiere personnelle accessible. Les fonctions premium doivent rester clairement separees et reservees aux usages avances.

Table indicative :

| Socle de base gratuit | Fonctions premium envisagees |
|---|---|
| Comptes essentiels | Multi-profils / foyers avances |
| Transactions et imports de base | Analyses avancees |
| Budgets simples | Scenarios patrimoniaux et projection enrichie |
| Dashboard principal | Exports et rapports avances |
| Patrimoine simple | Options securite / sauvegarde renforcees |

Attention : cette table reste indicative tant que l'offre premium n'est pas finalisee.

### 6. Etat du projet

Message :

CTA :

## Campagne LinkedIn associee

### Post 1 - Parti pris

Angle : pourquoi Valoria Vision ne mise pas sur une connexion bancaire permanente imposee.

Formulation cle :

> Automatiser ce qui peut l'etre localement, sans rendre l'utilisateur dependant d'une synchronisation bancaire permanente.

### Post 2 - Confidentialite

Angle : les donnees financieres racontent beaucoup plus qu'un solde.

Formulation cle :

> Les donnees financieres personnelles doivent rester sous controle.

### Post 3 - Automatisation maitrisee

Angle : l'automatisation n'est pas abandonnee, elle est deplacee vers les imports, la reconnaissance et les traitements locaux.

Formulation cle :

> Valoria Vision n'est pas contre l'automatisation. Il est contre l'automatisation opaque.

### Post 4 - Socle gratuit + premium

Angle : rendre l'usage essentiel accessible, puis reserver les besoins avances a une offre premium claire.

Formulation cle :

> Un socle de base gratuit, une trajectoire premium pour les usages avances.

### Post 5 - Direction graphique UI R8

Angle : montrer les maquettes avec prudence.

Formulation obligatoire :

> Maquette de direction graphique, non encore disponible dans la version actuelle.

### Post 6 - Appel beta

Angle : recruter des retours qualifies.

Formulation cle :

> Le projet avance vers une beta progressive. Les retours d'utilisateurs interesses seront precieux.

## Regle d'utilisation des maquettes UI R8

Les maquettes peuvent etre utilisees pour la communication si et seulement si :

1. elles sont clairement identifiees comme maquettes ;
2. elles restent techniquement realisables en Python/PySide6 ;
3. elles ne promettent pas une disponibilite immediate ;
4. elles ne montrent pas de donnees personnelles reelles ;
5. elles sont coherentes avec la future charte graphique ;
6. elles ne remplacent pas les captures reelles lorsque la version implementee sera disponible.

Mention courte recommandee :

> Direction graphique en cours - interface cible non encore disponible.
