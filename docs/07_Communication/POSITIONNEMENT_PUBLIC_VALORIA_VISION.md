# Valoria Vision - Positionnement public

Date de cadrage : 2026-08-28
Ticket lie : #67 COMM-1

## Objectif

Definir le discours public de reference pour Valoria Vision avant la refonte de la landing page et la reprise des publications LinkedIn.

Ce document sert de base commune pour :

- la page LinkedIn ;
- les publications LinkedIn ;
- la landing page ;
- les futures pages SEO ;
- les visuels et maquettes publiques ;
- les textes de presentation du projet.

## Message central

> Valoria Vision est une application locale de gestion financiere personnelle, concue pour donner une vision claire du cash, des comptes, des budgets, du patrimoine et du previsionnel, sans imposer de connexion bancaire permanente.

## Formulation courte

> Une vision claire du cash, des comptes et du patrimoine, avec une application locale et maitrisee.

## Formulation landing page

> Valoria Vision aide a suivre son cash, ses comptes, ses budgets et son patrimoine dans une application locale, avec un socle de base gratuit et des fonctions premium prevues pour les usages avances.

## Formulation LinkedIn

> Valoria Vision explore une autre approche de la gestion financiere personnelle : une application locale, sans connexion bancaire permanente imposee, avec une automatisation maitrisee et un socle de base gratuit.

## Positionnement produit

Valoria Vision n'est pas un simple outil de suivi bancaire.

Le projet vise a reunir dans une meme application :

- la vision des comptes bancaires ;
- le suivi des transactions ;
- les imports bancaires maitrises ;
- les budgets ;
- la tresorerie actuelle et previsionnelle ;
- le patrimoine ;
- les rapprochements entre previsions et transactions realisees ;
- a terme, des fonctions premium pour les besoins avances.

## Positionnement economique

Valoria Vision n'est pas uniquement freeware.

Le positionnement retenu est :

- un socle de base gratuit, utile et accessible ;
- une trajectoire premium pour les fonctions avancees ;
- une distinction claire entre ce qui releve de l'usage essentiel et ce qui releve d'un usage expert ou etendu.

Formulation recommandee :

> Valoria Vision repose sur un socle de base gratuit, avec une trajectoire premium pour les usages avances.

Formulations a eviter :

- "logiciel entierement gratuit" ;
- "freeware complet" ;
- "alternative gratuite a tous les logiciels financiers" ;
- "tout sera gratuit".

## Positionnement local-first

Valoria Vision fait le choix d'une approche locale et maitrisee.

Ce choix signifie :

- pas de connexion bancaire permanente imposee ;
- pas de dependance quotidienne a un agregateur ;
- pas de promesse d'automatisation opaque ;
- des imports, controles et traitements que l'utilisateur peut comprendre ;
- une meilleure maitrise de ce qui est partage ou non.

Formulation recommandee :

> Valoria Vision ne s'oppose pas a l'automatisation. Il privilegie une automatisation maitrisee, locale et comprehensible.

## Positionnement face aux agregateurs

La communication ne doit pas attaquer directement les concurrents ni affirmer que les solutions connectees seraient moins securisees.

Le bon angle est de comparer les modeles :

| Modele connecte | Approche Valoria Vision |
|---|---|
| Synchronisation bancaire automatique | Imports maitrises et routines locales |
| Dependances API et agregateurs | Traitement local et controle utilisateur |
| Forte automatisation immediate | Automatisation progressive et explicable |
| Connexion permanente possible | Pas de connexion bancaire permanente imposee |

Formulation recommandee :

> Certaines applications misent sur la synchronisation bancaire automatique. Valoria Vision fait un autre choix : automatiser ce qui peut l'etre localement, sans imposer une connexion permanente aux comptes bancaires.

Formulations a eviter :

- "les agregateurs ne sont pas securises" ;
- "Finary ou Agicap sont moins fiables" ;
- "Valoria Vision est inviolable" ;
- "nous sommes plus securises que les autres".

## Ton de communication

Le ton doit etre :

- clair ;
- sobre ;
- pedagogique ;
- factuel ;
- transparent sur l'etat du produit ;
- ambitieux mais non excessif.

Le projet est encore en construction. Il faut donc parler de direction produit, de recettage, de consolidation et de future beta, sans faire croire que tout est deja disponible.

## Promesses autorisees

La communication peut affirmer :

- que Valoria Vision est pense comme une application locale ;
- que le projet n'impose pas de connexion bancaire permanente ;
- qu'un socle de base gratuit est prevu ;
- que des fonctions premium sont envisagees ;
- que la nouvelle charte UI R8 est une direction graphique en cours ;
- que le recettage et la consolidation du produit continuent.

## Promesses a eviter

La communication ne doit pas affirmer :

- que l'application est deja commercialement disponible si ce n'est pas le cas ;
- que la nouvelle UI R8 est deja implementee ;
- que toutes les fonctions premium sont deja definies ;
- que Valoria Vision remplace completement les solutions existantes ;
- que les concurrents seraient moins securises ;
- que l'application est inviolable.

## Pitch 30 secondes

Valoria Vision est une application de gestion financiere personnelle en construction. Son objectif est d'aider a suivre clairement son cash, ses comptes, ses budgets, son patrimoine et ses previsions dans un environnement local et maitrise. Le projet fait le choix de ne pas imposer de connexion bancaire permanente a un agregateur. Il vise un socle de base gratuit, avec des fonctions premium prevues pour les usages avances. L'ambition est de proposer un outil clair, fiable et coherent, construit progressivement avec une attention particuliere portee a la confidentialite, aux imports maitrises et a la qualite des donnees.
