# Suivi landing page - maquettes produit

Date : 2026-08-29
Site public : https://valoria-vision.fr
Dossier de reference : docs/07_Communication

## Objectif

Documenter la mise a jour de la landing page Valoria Vision actuellement publiee, afin de garder une trace claire des choix UX, des choix de communication et des maquettes produit retenues.

La page doit montrer la valeur concrete du produit sans donner une impression de catalogue. Elle doit aussi rester coherente avec le positionnement public deja pose : application locale de gestion financiere personnelle, socle gratuit, trajectoire premium future, donnees traitees sous controle utilisateur.

## Changements retenus sur la landing page

| Zone | Decision |
|---|---|
| Navigation mobile | Remplacer les onglets visibles par un menu hamburger en haut a gauche. |
| Navigation desktop | Garder une navigation lisible : Produit, Ecrans, Histoire, Offre, Feuille de route. |
| Redondance | Supprimer le doublon visible autour du libelle Fonctionnalites. |
| Storytelling | Ajouter une section expliquant la creation du produit par un ancien professionnel de la tresorerie et de la gestion financiere. |
| Retour haut de page | Conserver un bouton flottant de remontee rapide pour les longues pages. |
| Maquettes produit | Ajouter une section Ecrans & choix techniques avec une selection courte de visuels forts. |

## Maquettes retenues

| Ecran | Raison de selection |
|---|---|
| Dashboard | C'est l'ecran le plus demonstratif : KPIs, cash disponible, patrimoine net, depenses, alertes et courbe de tresorerie. |
| Imports bancaires | Il illustre l'approche locale : fichier importe, reconnaissance, controles, doublons ignores, validation avant integration. |
| Budgets | Il montre la comparaison prevu / realise, les ecarts et la lecture rapide par categorie. |
| Rapprochements | Il explique une valeur metier forte : relier les transactions reelles aux previsions avec score de correspondance. |

## Maquettes non retenues dans la landing actuelle

| Ecran | Raison |
|---|---|
| Comptes bancaires | Utile produit, mais moins differenciant pour la promesse publique que le dashboard, les imports et les rapprochements. |
| Parametres / regles auto | Interessant techniquement, mais trop interne pour une premiere lecture marketing. |

Ces ecrans pourront etre reutilises plus tard dans une page produit detaillee, une documentation beta ou une publication LinkedIn technique.

## Message produit a renforcer

Valoria Vision n'est pas seulement une liste de modules. Le discours doit partir du besoin utilisateur :

> reprendre une vision claire du cash, des comptes bancaires et du patrimoine, avec une application locale, graphique et controlee par l'utilisateur.

Les maquettes doivent donc servir trois preuves simples :

- lisibilite : KPIs, courbes, repartitions et alertes utiles ;
- fiabilite : soldes de reference, controles d'import, rapprochements et qualite des donnees ;
- maitrise : donnees locales, imports controles, absence de connexion bancaire permanente imposee.
