# 08 - Releases

Pour chaque version publiée, conserver :

- la note de version ;
- le ZIP ou l'installateur de référence, ou son lien ;
- la matrice de recette finalisée ;
- la décision GO / NO GO ;
- les anomalies connues ;
- la procédure de retour arrière.

Ne pas déposer de base utilisateur réelle dans ce dossier.
