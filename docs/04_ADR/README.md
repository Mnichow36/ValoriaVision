# 04 - ADR

ADR signifie Architecture Decision Record.

Chaque ADR conserve :

- le contexte ;
- la décision ;
- les solutions envisagées ;
- les conséquences ;
- la date et le statut.

Les premiers ADR seront créés en Phase 2 : menus contextuels, règles de solde, archivage des comptes, synchronisation des listes et formulaire création/modification.
