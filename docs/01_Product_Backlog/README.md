# 01 - Product Backlog

Le Product Backlog est la liste officielle de tous les travaux connus.

## Règles de mise à jour

- Une nouvelle anomalie ou fonctionnalité reçoit un ID unique.
- L'issue GitHub correspondante est créée ou liée.
- La priorité et la version cible sont renseignées.
- Le statut est mis à jour après développement et recette.
- Une ligne n'est jamais supprimée : elle peut être marquée Annulée ou Remplacée.
