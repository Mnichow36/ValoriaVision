# Points ouverts — Valoria Vision V0.6.6-R7.2.2 Import Fix

## Rapprochements

Le module Rapprochements doit être recetté après validation du module Import / Transactions. Les corrections profondes de rapprochement ne sont pas incluses dans cette version courte.

## Interface complète

Le format `JJ/MM/AAAA` et les montants à deux décimales ont été renforcés dans les principaux écrans. La recette utilisateur doit confirmer qu'aucune zone résiduelle ne conserve un format technique.

## Données existantes

Si le fichier SG a déjà été importé dans une version précédente avec des libellés pauvres, il est recommandé d'annuler cet import ou de repartir d'une base propre pour tester les doublons avec les libellés enrichis.
