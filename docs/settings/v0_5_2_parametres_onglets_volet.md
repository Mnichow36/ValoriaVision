# V0.6.0 — Paramètres : navigation par onglets & volet latéral

## Objectif

Réorganiser l’écran Paramètres afin d’éviter les longs blocs verticaux et d’améliorer la lisibilité.

## Ajouts

- Onglets :
  - Vue d’ensemble
  - Sécurité
  - Diagnostic
  - Cohérence métier
  - Maintenance
- Volet latéral droit de détail.
- Synthèses compactes dans les onglets.
- Détails longs déplacés dans le volet.
- Actions sauvegarde/restauration conservées.

## Bénéfices

- Plus de surcharge dans le bloc Diagnostic.
- Meilleure séparation entre sécurité, technique et métier.
- Meilleure base pour les futurs paramètres Premium.
