# 06 - UX Guidelines

Ce dossier accueillera le standard UX de Valoria Vision en Phase 2.

Décisions déjà retenues :

- la table Transactions devient la référence des listes ;
- menus contextuels par clic droit et bouton ⋮ ;
- colonnes lisibles et non tronquées ;
- actions cohérentes entre vue tableau et vue cartes ;
- affichage sobre, moderne et homogène.
