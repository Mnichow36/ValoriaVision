# Documentation Valoria Vision

Cette arborescence sépare les différents types de documents afin de conserver une source de vérité claire.

| Dossier | Usage |
|---|---|
| `00_Gouvernance` | Méthode projet, procédures, guide GitHub et modèles |
| `01_Product_Backlog` | Référentiel des travaux à faire, en cours ou terminés |
| `02_Roadmap` | Trajectoire des versions et critères GO / NO GO |
| `03_Cahier_des_Charges` | Exigences fonctionnelles et règles métier |
| `04_ADR` | Décisions d'architecture et raisons associées |
| `05_Recette` | Matrices de tests, anomalies et décisions qualité |
| `06_UX_Guidelines` | Standards d'interface et d'ergonomie |
| `07_Communication` | Stratégie, contenus et suivi de communication |
| `08_Releases` | Notes de version, packages et validations de sortie |

## Convention de nommage

```text
ValoriaVision_<Type>_<Sujet>_V<Numéro>.<extension>
```

Exemples :

- `ValoriaVision_CDC_Gestion_Comptes_V1.pdf`
- `ValoriaVision_ADR_003_Archivage_Comptes.md`
- `ValoriaVision_Recette_V0_6_7.xlsx`
