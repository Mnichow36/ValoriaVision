VALORIA VISION — V0.6.6-R7.2.4 LOT 3
======================================

Version groupée de recette : UX Import, Comptes bancaires et Rapports centralisés.

Objectif de cette version
-------------------------
Cette version sert à tester un lot cohérent de correctifs R7.2 :

1. Import Société Générale CSV déjà stabilisé.
2. Détection du compte bancaire source.
3. Prévention des faux doublons, notamment l'anomalie #53.
4. Audit technique des lignes d'import.
5. Rapport d'import généré automatiquement.
6. Message clair en cas de réimport 100 % doublon.
7. Progression visuelle pendant l'import.
8. Gestion enrichie des comptes bancaires : N° de compte / RIB et IBAN.
9. Préparation de la reconnaissance des IBAN internationaux.
10. Modification contrôlée des comptes bancaires.
11. Suppression ou archivage sécurisé des comptes.
12. Consultation des rapports d'import depuis le menu Rapports.

Ce que cette version ne couvre pas encore complètement
------------------------------------------------------
Cette version ne constitue pas encore la livraison complète CDC R7.2.

Restent notamment à traiter dans les lots suivants :

- annulation d'import complètement durcie ;
- recalculs synchronisés complets après annulation ;
- rapprochements N↔N ;
- groupes de rapprochement ;
- historique complet des rapprochements ;
- transitions avancées de statut ;
- rollback complet de migration ;
- recette complète REC-01 à REC-28.

Installation / lancement
------------------------
Si vous utilisez l'archive produite par GitHub Actions :

1. Décompresser l'archive ZIP dans un dossier neuf.
2. Utiliser de préférence un chemin court, par exemple C:\VV\R724\, afin d'éviter les chemins Windows trop longs.
3. Ouvrir le dossier Valoria Vision.
4. Lancer Valoria Vision.exe.

Sécurité des données
--------------------
Ne jamais versionner ni partager :

- data/valoria_vision.db
- data/secure/
- data/security/
- data/backups/
- fichiers .vvdb
- fichiers .key
- relevés bancaires réels non anonymisés

Recette conseillée Lot 3
------------------------
Tester en priorité :

1. Démarrage application.
2. Titre de fenêtre R7.2.4 Lot 3 visible.
3. Identifiants de comptes masqués.
4. Création d'un compte avec N° de compte / RIB et IBAN.
5. Saisie d'IBAN internationaux valides.
6. Modification d'un compte sans modifier le solde initial.
7. Suppression d'un compte vide.
8. Blocage ou archivage d'un compte contenant des données liées.
9. Import du fichier Société Générale.
10. Progression visuelle pendant l'import.
11. Rapport d'import généré après validation.
12. Rapport retrouvé dans le menu Rapports.
13. Réimport identique détecté comme 100 % doublon.
14. Cohérence des transactions affichées après import.
